Modal

Modals focus attention on a single task. This pattern combines the Figma Modal Type=Slot layout with the Search-input field for filterable slot content.

Overview

Use when users must complete or dismiss a focused flow: pick items from a searchable list, confirm settings, or review content in a centered dialog. Pair a Primary footer action with a Secondary cancel action. Keep one Primary button per modal.

Design note: Figma documents Modal and Search-input as separate components. This page describes their composed pattern for product UI.

Usage Guidelines

  • Use for focused tasks that block the page until completed or dismissed.
  • Place the search field directly under the header when the slot lists filterable items.
  • Use Secondary for cancel and Primary for the main action. Only one Primary per modal.
  • Keep titles short. Use the subtitle for context, not essential instructions.
  • Return focus to the trigger element when the modal closes in production apps.

Destructive confirmation

Swap the Primary button to the Danger variant when the main action is destructive.

Accessibility

Dialog semantics

Use role="dialog", aria-modal="true", and aria-labelledby pointing at the title. Set aria-hidden="true" on the page behind the modal while open.

Search field

Provide a visible <label> or aria-label on the search input. Use type="search" for appropriate browser behavior.

Keyboard

Escape closes the modal. Tab order runs header, search, slot focusables, footer buttons. Production apps should trap focus inside the dialog while open and restore focus to the opener on close.

Close control

The icon-only close button requires aria-label="Close". Decorative icons use aria-hidden="true".

  <div class="spark-modal-overlay" aria-hidden="true"></div>
  <div class="spark-modal-panel" role="dialog" aria-modal="true"
    aria-labelledby="modal-title">
    <header class="spark-modal-header">
      <div class="spark-modal-header-text">
        <h2 class="spark-modal-title" id="modal-title">Select items</h2>
        <p class="spark-modal-subtitle">Search and choose entries.</p>
      </div>
      <button type="button" class="spark-btn spark-btn-ghost spark-btn-icon-only spark-btn-small"
        aria-label="Close">...</button>

    <div class="spark-modal-search">
      <div class="spark-search-input-wrap">
        <input type="search" class="spark-search-input" placeholder="Search"
          aria-label="Search items" />
        <svg class="spark-search-input-icon" aria-hidden="true">...</svg>
      </div>
    </div>
    <div class="spark-modal-body">
      <!-- slot content -->
    </div>
    <footer class="spark-modal-footer">
      <button class="spark-btn spark-btn-secondary spark-btn-medium">Cancel</button>
      <button class="spark-btn spark-btn-primary spark-btn-medium">Confirm</button>
    </footer>
  </div>
