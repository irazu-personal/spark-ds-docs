Colors & Tokens

Spark uses a 3-tier token architecture: Primitive tokens define raw color values, Semantic tokens assign contextual meaning, and Component tokens scope usage to specific UI elements.

Token Architecture

Primitive

Raw values

--primitive-blue-500
→

Semantic

Purpose-driven aliases

--semantic-content-brand
→

Component

Scoped to UI elements

--semantic-button-primary-bg

Semantic Tokens

Semantic tokens map primitive values to contextual roles. Use these instead of primitives in production code.

Border

Swatch Token Name Value (reference) Description Usage
--semantic-border-active primitive-blue-500 Used for active/selected element borders Input focus, selected tabs
--semantic-border-dark primitive-neutral-700 Used for high-contrast dark borders Dividers on light surfaces
--semantic-border-default primitive-neutral-300 Default border for containers and dividers Cards, inputs, tables
--semantic-border-inverse primitive-neutral-0 Border for elements on dark surfaces Elements on inverse backgrounds
--semantic-border-strong primitive-neutral-500 Prominent borders requiring more visual weight Emphasized containers

Content

Swatch Token Name Value (reference) Description Usage
--semantic-content-brand primitive-blue-500 Brand-colored text and icons Links, branded labels
--semantic-content-inverse primitive-neutral-0 Text and icons on dark/inverse backgrounds Text on filled buttons, dark cards
--semantic-content-primary primitive-neutral-900 Default text and icon color for body content Headings, body text, primary icons
--semantic-content-secondary primitive-neutral-600 Supporting text with less emphasis Captions, helper text, timestamps
--semantic-content-tertiary primitive-neutral-500 Lowest emphasis text Placeholder text, disabled labels

Surface

Swatch Token Name Value (reference) Description Usage
--semantic-surface-brand primitive-blue-500 Brand-colored background Banners, highlighted sections
--semantic-surface-canvas primitive-neutral-50 App-level page background Body/root background
--semantic-surface-inverse primitive-neutral-900 Inverted dark background for contrast areas Dark cards, tooltips, overlays
--semantic-surface-muted primitive-neutral-100 Slightly tinted background for grouped areas Sidebar backgrounds, code blocks
--semantic-surface-subtle primitive-neutral-200 Subtle differentiation surface Hover states, secondary panels
--semantic-surface-sunken primitive-neutral-100 Recessed background to indicate depth Inset containers
--semantic-surface-tooltip primitive-neutral-800 Background for tooltip popups Tooltips
--semantic-surface-white primitive-neutral-0 Pure white surface, always remains white Cards, modals, dropdowns
