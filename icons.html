Icons

130 outlined icon sets from the Spark Figma library. Each set ships as two SVG files: medium (24px) and small (16px). Download files from this page or use them directly from the repository.

File location

All SVGs live in assets/icons/ in this repo. Filenames use kebab-case: {name}-medium.svg and {name}-small.svg (for example search-medium.svg, chevron-left-large-small.svg).

Published docs mirror the same paths, so a medium search icon is at assets/icons/search-medium.svg relative to the site root.

Size tokens

VariantFile suffixTokenDimensions
Medium-medium.svg--semantic-button-icon-size-medium24px
Small-small.svg--semantic-button-icon-size-small16px

Match the SVG variant to the component size. Do not scale a small file up to medium in CSS.

Developers

  • Import the file you need, for example assets/icons/search-medium.svg.
  • In React, override fill with currentColor so icons follow text color tokens.
  • Set size with --semantic-button-icon-size-medium or --semantic-button-icon-size-small, not arbitrary px in JSX.
  • Use aria-hidden="true" on decorative icons; the parent control must have an accessible name.

Designers

Source of truth in Figma is Icons Outlined in the Spark DS file. These SVGs are exports for handoff, prototypes outside Figma, and engineering builds. Prefer the Figma component when designing inside the library.
